# 🖼️ Documentation Assets

Use this directory for project-specific illustrations, original SVG diagrams, and genuine screenshots.

## 📸 Screenshots
- Capture screenshots from the actual running page.
- Record viewport dimensions, browser, and commit.
- Never fabricate an implemented feature in a screenshot.
- Use descriptive filenames and meaningful alternative text in documentation.
- Optimize file size while preserving readable detail.

## 🎨 Diagrams
Keep editable Mermaid source in docs/diagrams/. Store original SVG exports here when a static visual is useful in GitHub previews or external documentation.

## ⚖️ Provenance
Record source, author, license, and attribution for external assets. Existing product imagery remains under the original Images/ directory. Do not assume the project code license automatically covers third-party imagery.
