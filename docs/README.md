## ⚠️ Documentation policy

Documentation is not a substitute for implementation. Mark proposals as proposed, tests as not run until executed, and risks as open until addressed. Do not claim accessibility conformance, performance scores, security certification, production deployment, or commerce functionality without evidence.

When code changes, update the relevant guide, diagram, checklist, and project structure. Keep local links valid and preserve exact path casing.
