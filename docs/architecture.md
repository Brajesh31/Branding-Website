# Architecture

## System overview

Fabulo is a single-document static website. The browser renders the HTML in the repository root, loads local images and generated CSS by relative URL, and also loads Tailwind's browser CDN script over HTTPS. There is no application server or client-side JavaScript module in this repository.

    Visitor browser
       |-- GET /
       |-- GET /Images/...
       |-- GET /css/style.css (generated by the build)
       |-- GET https://cdn.tailwindcss.com
       |
    Static file host
       |-- index.html
       |-- Images/
       |-- css/style.css

The browser-CDN request is external to the static host. If that host is unavailable or blocked by a network policy, CDN-provided styling may not be applied. The local CSS build is a separate Tailwind CLI path; this project currently includes both the generated CSS link and the CDN script.

## Source layout

| Path | Responsibility |
| --- | --- |
| **index.html** | Page metadata, brand header, collection content, promotional sections, and footer. |
| **input.css** | Tailwind base, component, and utility directives used by the CLI build. |
| **tailwind.config.js** | Tailwind configuration; its content glob scans root-level HTML files. |
| **package.json** | Project scripts and Tailwind development dependency. |
| **package-lock.json** | Locked npm dependency graph. |
| **Images/** | Local SVG and JPEG presentation assets referenced from the HTML. |
| **css/style.css** | Generated Tailwind output referenced by the HTML; ignored by Git and recreated during a build. |

## Rendering and styling

The page structure and copy live in **index.html**. Utility classes use Tailwind syntax, including arbitrary values. The Tailwind CLI reads **input.css**, scans files matched by the content configuration, and writes the generated stylesheet to **css/style.css**. The same HTML also loads the browser CDN script. Because both paths are present, the project's precise production CSS strategy should be decided and documented before removing either path.

## Runtime boundaries

- All page content and promotional copy are static markup.
- The buttons have no event handlers or destinations.
- Social and footer labels are plain text, not linked accounts or routes.
- There is no API client, form submission, server-side rendering, database, cookie/session logic, or user data persistence.
- No project-owned analytics code or environment variables are configured.
- Image and SVG requests are served from the local **Images/** directory.

## Operational implications

Deploy the repository root as static files after generating the CSS required by the page. Preserve case in paths; for example **Images/** differs from **images/** on case-sensitive hosts. See [Deployment](deployment.md).
